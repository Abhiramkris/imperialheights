# imperialheights

Heritage luxury hotel website for Ashoka Imperial / Imperial Heights in Kochi, Kerala.

## Features
- **Old-School Heritage Vibe**: Built with warm moss green, soft sage, antique cream, and classic editorial serif typography.
- **Floating Pill UI**: Floating navigation bar, overlapping reservation search bar, rounded accommodation cards, and interactive modal dialogs.
- **Rich Content**: 5 room categories with transparent desk pricing, interactive amenities explorer, grand banquet hall showcase, The Imperial Spice restaurant, photo gallery, Google reviews carousel, and FAQ accordion.
- **Interactive Reservation**: Stay cost calculator, callback request system, and direct WhatsApp desk inquiry.

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- Lucide React Icons

## Getting Started
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```
